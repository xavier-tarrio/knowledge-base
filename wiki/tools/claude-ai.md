# Claude.ai

## What it does
The primary web, desktop, and mobile interface for Claude. The most general-purpose surface — covers: conversational chat, Research mode, file creation (via Skills), Projects, Connectors, and extended thinking. The starting point for most Claude users and the interface through which most features are accessed.

## When to use it
- General tasks: writing, analysis, summarization, brainstorming
- Research: complex multi-source investigations (Research mode)
- Document creation: Excel, Word, PowerPoint, PDF (via built-in Skills)
- Persistent workspaces: Projects for recurring work streams
- Connected integrations: Connectors for live data from your tools
- Mobile: access Claude on the go

## Key features accessible from claude.ai
| Feature | What it enables |
|---------|----------------|
| Projects | Persistent knowledge + instruction workspaces |
| Skills | Repeatable process execution, document creation |
| Research | Agentic multi-source investigation |
| Connectors | Live access to external tools and data |
| Extended thinking | Deep reasoning on complex problems |
| Web search | Real-time information access |

## When NOT to use it
- **Software development in your codebase**: use [[tools/claude-code]] instead — it has full repo awareness and can execute
- **Local file/app access**: use [[tools/claude-desktop]] with desktop extensions
- **Spreadsheet work in Excel context**: use Claude for Excel (sidebar)

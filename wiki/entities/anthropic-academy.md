# Anthropic Academy

## What it is
Anthropic's official learning platform at `anthropic.skilljar.com`. Offers structured, certificate-bearing courses on using Claude effectively. The primary source for the initial knowledge base in this wiki.

## Key courses ingested
- **Claude 101** — 9-lesson foundational course covering: projects, prompting, desktop modes, skills, connectors, research mode, integrations, and use cases by role. ~2 hours total estimated time.
- **AI Fluency Framework Foundations** — academic framework course by Rick Dakan & Joseph Feller. Introduces the [[concepts/ai-fluency]] meta-framework, [[concepts/4d-framework]], and [[concepts/ai-collaboration-modes]]. Released CC BY-NC-SA 4.0.

## Relevance to course building
The structure and framing of Anthropic Academy courses is a reference point for how Anthropic communicates its products. Building your own courses on Claude Code should align with or deliberately differentiate from this official framing.

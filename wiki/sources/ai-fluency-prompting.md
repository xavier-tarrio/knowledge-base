# AI Fluency: Effective Prompting Techniques

## Summary
Practical deep dive into prompt engineering within the AI Fluency framework. Introduces six foundational techniques and troubleshooting strategies. Positioned as the operational toolkit for the Description competency.

## Key takeaways
- Six foundational techniques: give context, show examples, specify constraints, break into steps, ask AI to think first, define role/tone
- Secret weapon: ask the AI to help improve your own prompt
- Prompting is iterative — expect to refine based on results
- Common successful patterns: clear task overview, format specs, explicit constraints, relevant background
- Prompt engineering = familiar human communication principles + AI-specific considerations

# Claude 101: Other Ways to Work with Claude

## Summary
Lesson surveying Claude surfaces beyond claude.ai: Claude Code (agentic coding in terminal/IDE), Claude in Slack (team collaboration and coding from chat), Claude for Excel (spreadsheet analysis and modeling), and Claude for Chrome (browser automation and research). Includes a summary table of all Claude surfaces with their primary use cases.

## Key takeaways
- Claude is an intelligence; claude.ai is just one interface — each specialized surface meets you where you already work
- **Claude Code**: agentic coding tool in terminal/IDE/browser/Slack. Understands entire codebase, executes commands, runs tests, creates commits. The engineering surface.
- **Claude in Slack**: draft responses, summarize threads, prep for meetings, tag @Claude to spin up Claude Code sessions directly from bug reports or feature discussions
- **Claude for Excel**: sidebar that analyzes multi-tab workbooks, debugs formula errors (#REF!, #VALUE!, circular references), builds models, creates pivot tables
- **Claude for Chrome**: browser sidebar that summarizes pages, drafts email responses, fills forms, automates multi-step web workflows — currently in research preview
- The surface you choose should match where your work lives, not require context-switching

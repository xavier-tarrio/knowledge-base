# AI Fluency: A Closer Look at Description

## Summary
Deep dive into Description — the second 4D competency. Introduces three types: Product Description (what you want), Process Description (how to approach it), and Performance Description (how the AI should behave). Frames AI as a collaborative partner, not a database or vending machine.

## Key takeaways
- Description has three sub-components: Product (what), Process (how), Performance (behavior)
- Product Description: define outputs, format, audience, style
- Process Description: guide the AI's approach — often as important as the end goal
- Performance Description: specify communication style, verbosity, tone
- AI cannot read your mind — quality of results directly reflects quality of communication
- Description and Discernment form a continuous feedback loop

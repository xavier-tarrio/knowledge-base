# Claude 101: Working with Skills

## Summary
Lesson introducing Claude Skills — instruction packages that encode repeatable workflows and execute them consistently. Covers Anthropic's built-in Skills (document creation), custom Skill creation via conversation, enabling Skills in settings, and the critical distinction between Skills (process) and Projects (knowledge).

## Key takeaways
- Skills are folders of instructions, scripts, and resources that Claude loads dynamically for specialized tasks — they make Claude's behavior on a task repeatable and systematic
- **Built-in Anthropic Skills** (available to all paid users): enhanced Excel, Word, PowerPoint, and PDF creation — Claude invokes them automatically
- **Custom Skills** are created by describing a workflow to Claude in conversation — no code required; Claude interviews you, you upload reference materials, Claude generates the skill file
- Skills can work with your actual uploaded files — upload a spreadsheet, Claude creates an updated version; results are downloadable or saveable to Google Drive
- The **Projects vs. Skills mental model**: Projects = knowledge hubs (what to know); Skills = process machines (how to execute). They complement each other — a skill can reference a project's knowledge.

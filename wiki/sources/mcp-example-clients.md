# MCP Example Clients

## Summary
Community-maintained list of 113 applications that support MCP as of mid-2025. Categorizes clients by supported feature set: Resources, Prompts, Tools, Discovery, Sampling, Elicitation, OAuth, Tasks, and interactive Apps.

## Key takeaways
- 113+ MCP clients in the ecosystem — MCP is already a broad standard, not a niche protocol
- Feature support varies significantly by client; not all clients implement all primitives (many support only Tools)
- Key clients: Claude Desktop/Claude Code (Anthropic), VS Code (GitHub Copilot), Cursor, Windsurf, Zed — most developer-facing tools support at least Tools
- Elicitation and Tasks are newer features with less client support

## Connections
Reference for evaluating which features you can rely on across the client ecosystem. If you want broad compatibility for a public MCP server, focus on Tools (universally supported) before Resources or Prompts.

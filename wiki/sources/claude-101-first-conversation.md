# Claude 101: Your First Conversation with Claude

## Summary
Foundational lesson covering how to structure effective prompts and set the right expectations for working with Claude. Introduces the three-part prompt framework (set the stage, define the task, specify rules) and the iterative mindset for getting better results.

## Key takeaways
- The three-part prompt structure: (1) set the stage — who you are, what you're working on; (2) define the task — what you want; (3) specify rules — format, tone, constraints, examples
- Claude performs better with specific context than generic requests — "write an email" vs. "write an apology email to our enterprise client about a second delay"
- Prompting is a conversation, not a one-shot command — iteration is built into the workflow
- Claude's defaults (helpful, professional, moderate length) are starting points you can override by being explicit
- Format specification works best with examples, not just descriptions

# Claude 101: Claude Desktop App — Chat, Cowork, Code

## Summary
Lesson covering the Claude Desktop application and its three interaction modes: Chat (conversational), Cowork (complex multi-step task execution with document creation), and Code (software development). Explains when to use the desktop app vs. the web interface and what each mode enables.

## Key takeaways
- The desktop app offers three distinct interaction paradigms in one app — the right mode depends on task type and complexity
- **Chat** = standard conversational interface, same as claude.ai
- **Cowork** = multi-step complex task execution (research briefs, document creation, file organization) — the mode for outputs requiring multiple orchestrated steps
- **Code** = software development mode, full codebase awareness and execution — equivalent to Claude Code CLI but with a GUI
- The desktop app is required for desktop extensions (local MCP servers), which enable local file access and native app integration
- Mobile tasks can be dispatched to desktop Cowork mode via Dispatch

# What is the Model Context Protocol (MCP)?

## Summary
The official MCP introduction from modelcontextprotocol.io. Defines MCP as an open-source standard for connecting AI applications to external systems and establishes the core USB-C analogy. Lists the broad ecosystem of clients that support MCP as of 2025.

## Key takeaways
- MCP connects AI applications to data sources (files, databases), tools (search, calculators), and workflows (prompts) through a standardized interface
- The USB-C analogy: just as USB-C unified device charging, MCP unifies how AI connects to tools — build once, works everywhere
- Benefits are different for each stakeholder: developers (less integration code), AI apps (ecosystem access), end-users (more capable assistants)
- Broad ecosystem: Claude, ChatGPT, VS Code, Cursor, and 110+ other clients support MCP

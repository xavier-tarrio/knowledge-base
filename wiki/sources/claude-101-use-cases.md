# Claude 101: Claude in Action — Use Cases by Role

## Summary
Practical lesson mapping Claude use cases to professional roles, with links to step-by-step guides in Anthropic's Use Case Gallery. Covers general professional use, sales, marketing, finance, HR, legal, and research roles. Serves as a reference for "where to start" when introducing Claude to a new user with a specific job function.

## Key takeaways
- Use cases are most effective when framed by role — "Claude for analytics" is more actionable than generic prompting advice
- **General**: project status reports, user feedback analysis, packaging brand guidelines as a Skill
- **Finance**: building financial models, drafting investment memos, inheriting and extending complex spreadsheets
- **Research**: planning literature reviews, verifying statistics from raw data
- **Sales**: battle card libraries, deal preparation, pipeline reports
- **Analytics/Data**: verifying statistics, analyzing patterns in feedback, building models — overlaps with Research role
- Anthropic maintains a Use Case Gallery at claude.com/resources/use-cases with step-by-step guides

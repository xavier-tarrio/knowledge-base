# Claude 101: Getting Better Results

## Summary
Practical lesson on troubleshooting common Claude failure modes, developing an iteration mindset, and systematically evaluating Claude's performance on your specific workflows. Introduces the 4D AI Fluency framework (Delegation, Description, Discernment, Diligence) and a lightweight eval methodology for recurring tasks.

## Key takeaways
- Common failure modes and their fixes: too generic → add specificity; wrong length → be explicit; wrong format → show an example; wrong tone → describe it in plain language; confident but wrong → verify independently and ask Claude to cite sources
- The iteration mindset: treat first drafts as starting points; give specific feedback ("cut paragraphs 1-2") not vague feedback ("make it better"); know when to start fresh vs. refine
- **4D AI Fluency framework**: Delegation (what goes to AI vs. human), Description (how to communicate with AI), Discernment (evaluating AI outputs), Diligence (responsible use)
- Evals don't require infrastructure — gather 5-10 examples, run test prompts, compare outputs, refine; learn what context to add and which tasks need human review
- Your workflows are unique — generic benchmarks don't apply; run your own evals to understand where Claude excels on *your* tasks

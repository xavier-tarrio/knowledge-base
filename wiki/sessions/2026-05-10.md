## Key insights
- MCP ≡ "USB-C for AI" — the integration distribution layer that eliminates M×N custom integrations
- The three primitives have distinct owners: Tools (model), Resources (application), Prompts (user) — getting this right is the core server design decision
- MCP ≠ Tool Use: MCP determines who *writes* the tool definitions; Tool Use is how Claude *calls* them
- Security threats are AI-specific: prompt injection via external content, tool poisoning via metadata, token passthrough (explicitly forbidden in spec)
- Enterprise adoption is real: 30% cost reduction + 45% consistency improvement in production case studies
